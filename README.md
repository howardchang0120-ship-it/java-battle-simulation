# Java Character Battle Simulation

A Java-based character battle simulation developed using object-oriented programming (OOP).

## Features

- Three character classes: Warrior, Witch, and Priest.
- Abstract ROLE class for shared character attributes and behaviors.
- Character-specific attacks using inheritance, method overriding, and polymorphism.
- Random selection of attackers and targets during battles.
- HP and MP management.
- Healing and magic recovery items using Drug, RedDrug, and BlueDrug classes.

## Technologies

- Java
- Object-Oriented Programming (OOP)
- Inheritance and Polymorphism
- Abstract Classes
- Arrays

## Project Structure

- ROLE.java — Abstract base class for characters.
- Warrior.java — Warrior character and attack skills.
- Witch.java — Witch character and attack skills.
- Priest.java — Priest character and attack skills.
- Drug.java — Base class for recovery items.
- RedDrug.java — HP recovery items.
- BlueDrug.java — MP recovery items.
- Main5.java — Main program and battle simulation.

## How to Run

Compile and run the Java source files using a Java Development Kit (JDK).

If the source files declare package a;, compile from the directory containing the a folder:

javac a/*.java
java a.Main5
